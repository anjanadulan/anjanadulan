> Full-stack e-bookshop platform built with **React**, **Tailwind**, **Spring Boot**, and **MySQL** microservice architecture.

### 📦 Distributor Management System
> Full-stack distribution management system featuring role-based dashboards, inventory tracking, order management, and analytics built with **Node.js**, **Express**, **PostgreSQL**, and **Prisma**.
